# 豫中防汛 · 开源参考实现

> 河南省中东部（郑州 — 许昌 — 漯河）防汛与台风极端降雨监控预警系统
> 一套面向**教学 / 原型 / 架构参考**的完整实现：系统设计方案 + Python 算法引擎 + 可交互 Demo。

---

## 先说清楚：这是什么，不是什么

**这是：**

- 一套开源的**参考架构与算法原型**，用来学习"一个防汛预警系统大概该怎么搭"。
- 包含可运行的代码：DFRI 综合风险指数、马斯京根洪水演进、概率化不确定性推演、数据质量评分、四级预警与撤离评估。

**这不是：**

- 不是经过业务化标定、可以用于真实防汛指挥的**生产系统**。
- 不能用来做真实的撤离决策，**不能替代**气象局 / 水利厅 / 防汛抗旱指挥部的官方预警。

## 快速开始

```bash
# 1) 克隆后进入目录
cd henan-flood-early-warning

# 2) 一键启动演示（自动起本地服务并打开浏览器）
python start.py

# 3) 想直接看算法效果，跑引擎自带 demo
python algorithms/flood_risk_engine.py
```

`start.py` 会自动选端口（默认 8090，被占用就 +1 试探）、启动静态服务器、并尝试打开默认浏览器；按 `Ctrl+C` 停止。
（特意用 `.py` 而不是 `.bat`，是为了避开中文路径下批处理文件的编码乱码问题。）

## 核心能力速览

| 模块 | 说明 |
|------|------|
| **DFRI 综合风险指数** | 降雨 / 地形汇水 / 水库承压 / 人口承灾 四维加权，支持数据质量因子 $Q_i$ 与自适应权重 |
| **概率化输出** | 蒙特卡洛 / 情景集合，给出点估计 + 5%~95% 分位区间，并分解主要风险驱动因子 |
| **马斯京根洪水演进** | 水库 → 河道 → 城区 的客水到达时间与超警概率推演 |
| **数据质量评分 (DQS)** | 缺失 / 时效 / 跳变 / 传感器状态综合打分，异常自动降权并触发插补降级 |
| **四级预警 + 闭环** | 蓝 / 黄 / 橙 / 红；含持续性 + 空间一致性复合触发、解除、复盘 |
| **可解释性** | 贡献度分解，让"为什么触发预警"说得清 |
